factor_loop_engine用大模型和演化算法自动发现有预测力的A股量化因子

一句话:把「设计因子 → 回测 → 筛选 → 迭代改进」这个量化研究员的核心工作循环,封装为一个 7×24 自动运行的闭环系统。

1因子是什么——用树表达式表示交易信号

在A股市场,一个量化因子就是一条「给每只股票打分」的规则。分数高的股票未来更可能涨(或跌)。比如「过去20天成交额的波动率低的股票未来表现更好」——这就是一个因子。

本项目把因子表示为表达式树(一种嵌套的函数调用结构),这既是人类可读的数学语言,也是计算机可执行的程序:

add(
zscore(std(rank_cs(log_mv), 20)),
add(
rank_cs(log_mv),
rank_cs(log_amount)
)
)

这个因子含义是:「市值排名的不稳定性 + 市值排名 + 成交额排名」的加权组合。它的每个组成部分:

元素含义角色
log_mv / log_amount对数市值 / 对数成交额叶子(数据字段)
rank_cs(x)每天把所有股票按 x 排名,映射到 [0,1]截面算子(跨股票比较)
std(x, 20)每只股票过去 20 天 x 的标准差时序算子(纵向滚动)
zscore(x)截面标准化(均值0、标准差1)截面算子
add(a, b)a + b(逐股票相加)逐元素算子

树的深度限制为 4 层——足够表达丰富的信号组合,又不至于过度复杂导致过拟合。

2数据——13 个基础字段,2015~2025 全A股

所有因子从这 13 个字段构建。数据来自 OSS 分钟K线,聚合为日频宽表(行=交易日,列=股票):

字段含义类型
adj_close / adj_high / adj_low复权收盘/最高/最低价价格
ret日收益率比率
overnight隔夜收益(今开/昨收-1)比率
intraday日内收益(今收/今开-1)比率
amplitude振幅(最高-最低)/收盘比率
up_shadow / down_shadow上影线/下影线占比比率
hl_ratio收盘位置(收-低)/(高-低)比率
log_volume / log_amount对数成交量/成交额量额
log_mv对数市值(close×流通股本)规模
为什么只有13个字段? 刻意保持精简——字段太多会让搜索空间爆炸,且容易找到虚假的「数据挖掘效应」。13个字段 × 14个算子 × 4层深度,组合空间已经足够大。

(~15%)

4.2 大模型怎么生成因子

系统定义了 12 个市场机制族(趋势动量、均值回归、边界突破、K线形态、跳空定价、波动压缩…),每个族附带经济学假设。每次调用 LLM 时:

你是A股量化研究员。基于下列因子语法,生成恰好一个因子表达式。

【算子(14)】 ma, std, max, min, roc, delta, skew, rank_ts,
             zscore, rank_cs, add, sub, mul, div
【可用字段】adj_close, adj_high, adj_low, overnight, intraday,
           amplitude, up_shadow, down_shadow, hl_ratio, ret,
           log_volume, log_amount, log_mv
【硬规则】s-表达式嵌套,最大深度4层;
         add/sub不得跨量纲;窗口为正整数

【目标机制】跳空与隔夜定价: 隔夜跳空, 隔夜延续, 日内回补
【经济学假设】隔夜信息不对称——机构在开盘前集中交易,
            隔夜跳空的方向和大小包含知情交易者的信号

只输出一个合法s-表达式。

LLM 返回如 sub(rank_cs(ma(overnight, 10)), rank_cs(ma(intraday, 10))),系统解析并验证其结构合法性。

为什么用大模型? 纯随机生成会产生大量无意义的组合(如 mul(volume, hl_ratio))。LLM 理解经济学含义,能生成有投资逻辑支撑的候选——同等搜索预算下,有效率远高于随机。

4.3 演化搜索

已入库的因子成为「父母」,通过变异(换一个叶子字段)和交叉(拼接两个因子的子树)产生「子代」。好的因子被反复变异精炼,差的自然淘汰——这就是演化算法的核心思想。

5.1 审查(回测前,快速淘汰结构缺陷)

检查项淘汰理由
跨量纲价格 + 成交量 → 单位不同,无意义
同质退化add(x, x) = 2x,冗余
过度嵌套std(std(x)) = 波动率的波动率,信号过度平滑
深度不足单字段(close)或单算子(ma(close,20))太简单
覆盖率塌陷某月覆盖率骤降 → 数据缺失或结构缺陷

5.2 回测(alphalab 真实历史模拟)

通过审查的候选被送入 alphalab 回测引擎,在 2018~2023H1 的真实历史数据上模拟交易:

  • 预测期:5 天(周频调仓)
  • 交易成本:单边 10bps
  • 股票池:中证全指,剔除 ST/停牌/涨停开盘
  • 预处理:MAD去极值 → 标准化 → 行业市值中性化 → 标准化

输出:IC(预测相关系数)、ICIR(预测稳定性)、多空年化收益、夏普比率、Calmar、分组单调性、逐年收益等。

5.3 十六项过滤(全部在样本内窗口计算)

维度阈值含义
\|IC\| > 0.03预测力足够因子值与未来收益的相关性
ICIR > 0.3预测稳定IC 的信息比率
每年多空 > 0不能有亏损年份2018~2023 六年全正
夏普 > 0.5风险调整收益整体+末年双重检查
Calmar > 1.0回撤可控年化/最大回撤
近9/12月 > 0近期仍在赚钱滚动检查
多头超额 > 0不能只靠做空多头组合也要跑赢
单调性 > 0.85分组收益单调递增十分组排序后收益递进
IC相关 < 0.70与库内已有因子不冗余或质量更优时替换旧的
同构子树 ≤ 2防结构集中防止同一半树反复出现

5.4 LLM 终审(最后一道关)

通过全部16项后,大模型收到表达式+回测指标+逐年收益分布,检查:

  • 经济学含义是否自洽
  • 收益是否集中在单一年份(→ 过拟合信号)
  • 多头是否无肉而多空尚可(→ 空头独撑)

拒绝理由如果是结构/经济学层面的,会被回流到该机制族的生成 prompt,让后续生成规避同类缺陷。

6防止过拟合——样本内/样本外分离

过拟合是量化因子最大的敌人——一个在历史上表现很好但对未来毫无预测力的因子,比没有因子更危险。本项目用时间切分来防御:

┌ 2015~2017 ─┬── 2018-01 ~ 2023-06 ──┬─ 2023-07 ~ 2024-12 ─┬─ 2025 全年 ─┐
│  预热数据    │      样本内 (IS)        │      隔离带          │   样本外     │
│ (不算指标)  │  16项筛选只看这里       │  (18个月缓冲)       │  (只报告)   │
└─────────────┴───────────────────────┴─────────────────────┴─────────────┘
样本内(IS)
2018~2023H1,5.5年。所有筛选、入库、替换决策只看这段数据。
隔离带
18个月,足够长窗口的滚动计算「预热」用,但不参与任何评测。
样本外(OOS)
2025全年。因子入库时自动回测一次存档,只报告、绝不参与筛选。
为什么OOS不能参与筛选? 一旦用2025年数据来决定「哪个因子入库」,2025就成了样本内——你永远失去了对这个挖掘流程的真·样本外评估。OOS的作用是事后诊断:如果整库OOS崩塌,说明挖掘流程本身过拟合了,需要人工调整。

7因子库的进化——保优淘劣

因子库不是只进不出的仓库,而是一个持续竞争的生态:

  • 新候选入库:通过全部16项+LLM终审 → 加入库
  • 保优淘劣:如果新候选与某个库内因子IC相关性 ≥ 0.70,且综合质量全面更优(×1.05),则替换旧因子
  • 同构限制:任何子树结构最多在库内出现2次,防止结构集中

结果是:库内因子始终是各个信号家族中历史最优的代表。随着挖掘轮次增加,弱因子被强因子替换,库整体质量单调上升。

7.1 运行节奏

深挖模式
连续有产出时
偏向变异+交叉精炼
⇄
探索模式
连续零产出时
偏向LLM+随机探索

系统在两种模式间自动切换:有新因子入库时进入深挖(在已知好结构附近精炼);连续多轮无产出时切换到探索(跳出当前邻域,寻找新信号源)。
