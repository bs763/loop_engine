1概述

把因子挖掘的"生成 — 审查 — 回测 — 过滤 — 入库"封装为定时调度、断点续跑的自动化闭环,2026-08-17/18 完成样本外验证体系改造:

IS-ONLY 准入
全部筛选只看样本内 2018-01~2023-06;OOS(2025)只存档报告,永不参与选择
GLM-5.3 双端
机制引导生成 + 带指标的 LLM 终审;拒因安全回流(结构类进族记忆,指标类永不回流)
结构先验防线
过度平滑/极值嵌套拒绝、同构家族保优淘劣、覆盖率防线、算子数值消毒

两条铁律:① 防 Goodhart——回测指标只在选择端(过滤/终审)流转,永不回流生成端;② OOS 样本外——2025 年数据只进 oos_metrics 存档与报告,任何筛选分支不读它。

当前库存(2026-08-18):11 个因子(全部按 IS 规则重准入过),iter 369,累计测试 1.5 万表达式。OOS(2025)首检:IC 全部持平或更强,夏普分化(头部 3.4+,尾部 1.0-1.4)。

数值消毒(三层,2026-08-17)

原始面板实测零 ±inf——inf 全由 div/roc 除零生成(分母字段零值率:overnight 10.3%/up_shadow 8.6%/down_shadow 7.6%)→ ①叶子求值入口消毒;②op_roc/op_div 输出消毒;③op_zscore 入口消毒(防单 inf 毒化整截面)。op_skew 为自研滚动矩实现(pandas rolling skew 有幽灵 NaN bug:53 万格窗口完整仍返回 NaN)。

4IS-ONLY 完整机制(如何使用、如何影响因子库)

4.1 是什么

所有准入判定(16 项过滤 + LLM 终审)只在样本内窗口 2018-01-01~2023-06-30 上计算;OOS(2025 全年)在入库瞬间被回测一次,结果存进因子记录的 oos_metrics 字段——只写不读(选择端代码路径完全不接触)。这是"样本外验证"的定义要求:选择过程必须对 holdout 失明,否则它就成了样本内。

4.2 一条因子的完整生命周期

生成(IS盲:不接触任何回测指标)
  → 确定性审查(结构层面,与窗口无关)
  → IS 回测(2018-01~2023-06 的 parquet + 同窗口 yaml)
  → 16 项过滤:逐年多空>0 查 2018-2023;末年夏普=2022H2~2023H1;
              近9/12月滚动相对 2023-06;IC/相关性/家族 全在 IS 序列上
  → LLM 终审(表达式 + IS 指标 + 逐年表 → 边界/经济/单年依赖)
  → 入库:记录 IS 指标 + IS ic_series + 【OOS 回测一次 → oos_metrics】
  → 日常:lib_status 的「IS→OOS 衰减表」展示每个因子 2025 真实表现
  → 出库:仅三种途径——被更优挑战者替换(保优淘劣,IS 口径)、
          结构治理(clean_library)、人工复检裁决(如 0007 冗余案)
     OOS 表现【永远不是】出库依据

4.3 对因子库的具体影响(已发生的历史)

事件机制结果
存量重准入(2026-08-17)全窗口时代入选的 15 个,按 IS 规则重跑回测+16 项+终审11 过 4 拒:2 个 IS 口径下撞 #9 相关(0.726/0.740)、1 个 IS |IC| 跌破 0.03、1 个被终审拒(div 分母振幅为零)——全窗口掩盖的冗余被清除
保优淘劣换血挑战者与在库者的质量比较全部用 IS 指标曾出现四连替换(1 个更优换掉 4 个相关/同构旧因子)
OOS 存档每个入库因子自动带 2025 指标首检:11 个 OOS IC 全部 ≥ IS IC(2025 风格友好),夏普分化暴露真实衰减

4.4 如何使用

日常全自动:每轮 run_round_cli.py 默认即 IS 准入 + OOS 存档,无需任何参数。手动工具:health_check.py 用库内 IS 指标复核阈值;lib_status.py 看衰减表;export_factors.py 导出全窗口(2018-2025)因子值供策略使用——因子值的导出与样本切分无关(切分约束的是评测)。

9LLM 终审与拒因回流(2026-08-18 升级)

过 15 项后、入库前(每轮 1-2 个)→ glm-5.3 收到:
  表达式 + 字段含义 + 算子语义说明 + 【IS 指标摘要 + 逐年多空表】
硬核对(先算后裁):①最大单年 > 其余年份总和 → 必拒
                  ②半数年份 |y|<2% → 倾向拒(单年依赖)
                  ③多头超额<1% 而多空尚可(空头独撑)→ 倾向拒
裁决 ACCEPT/REJECT + 一句理由
拒因自动分类:
  指标类(含 IC/夏普/年化/逐年 等词) → 只进台账
  结构/经济类(div 分母为零/量纲/滞后…) → add_family_note(族id, 理由)
      → family_notes.json 持久化 → 该机制族生成 prompt「已知缺陷,务必规避」栏
防火墙:指标可进选择端(终审诊断);指标数值/指标类结论 永不回流生成端

实测:单年依赖陷阱(2018 独赚 25%)正确 REJECT 并引用规则;健康因子通过且理由引用逐年分布。
