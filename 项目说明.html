1概述

把因子挖掘的"生成 — 审查 — 回测 — 过滤 — 入库"封装为定时调度、断点续跑的自动化闭环:

GLM-5.3 双端
机制引导生成 + 入库前 LLM 终审(智谱 Coding Plan,Anthropic 兼容端点)
结构先验防过拟合
审查过滤5 拒过度平滑/极值嵌套;过滤15 同构家族上限(保优淘劣语义)
断点续跑
检查点原子落盘,任意中断可恢复;失败候选自动重试

防 Goodhart(核心设计):生成端绝不接触回测指标——生成/审查只处理表达式,回测指标在后半段产生且不回流。代码层面强制(生成函数签名无指标参数)。

当前库存(截至 2026-08-17 轮 364):17 个因子,累计测试 14645 个表达式,Top|IC| 0.0737,两两相关体检 0 对 ≥0.7(41% 在 0.5~0.7 关注区)。当日完成:结构清洗(34→16)→ glm-5.3 双端切换 → 三道新闸(审查过滤5/过滤15/LLM 终审)→ 算子库三层消毒 → 覆盖率防线 → 复检移除冗余因子 0007(18→17)→ 相关性体检固化。

4生成层(GLM-5.3)

表达式 DSL

s-表达式,最大深度 4 层,14 算子:时序 ma(3-250) std/max/min/rank_ts(5-120) roc/delta(3-60) skew(10-120) · 逐元素 add sub mul div · 截面 zscore rank_cs。注意语义:min(x,120) 是 120 日滚动最小值(非数值截断);zscore 是逐截面标准化。

数值消毒(三层,2026-08-17):实测原始面板零 inf,±inf 全部由 div/roc 除零「生成」(分母类字段零值率高:overnight 10.3%/up_shadow 8.6%/down_shadow 7.6%)→ ①叶子求值入口 ±inf→NaN;②op_roc 修齐 op_div 口径(输出消毒);③op_zscore 入口消毒(防单个 inf 毒化整截面 mean/std)。其余算子有限输入→有限输出,无需处理。

五路生成预算(M3 动态)

每轮按近 5 轮入库表现自适应(yielding→利用+,stuck→探索+),当前基线 mutate 0.3 / crossover 0.3 / perturb 0.15 / random 0.1 / llm 0.15。父母种子取自库存因子。

LLM 机制引导(glm-5.3)

12 机制族
8 时序 + 4 截面(动量/波动/跳空/流动性…),每族带原型与经济学假设,prompt 引导生成
双重反偏置
字段使用频率→机制族 coverage(偏向未挖掘族)+ MECHANISM_BOOST(overnight 4x / intraday 2x / amplitude 2x 跳空优先)

兜底链:LLM 调用失败重试 1 次 → 全失败走 random_tree(不崩轮);输出非法 → 重试。每轮健康度自报告(见 §9 监控行)。

5审查层(确定性五道 + LLM 终审)

回测前的确定性关卡(engine/review.py,零 API 成本):

#规则动作依据
1截面算子直接嵌套截面(zscore(zscore(x)))简化(去外层)冗余
2add/sub/mul/div 两子树完全相同拒(退化为 2X/0/X²/1)同质退化
3add/sub 两操作数跨量纲(如 close+volume)拒量纲规则
4深度 ≤2拒(REVIEW_MIN_DEPTH=3)最小复杂度
5平滑算子直嵌平滑(std∘std / ma∘ma / std∘ma)
极值算子直嵌极值(max∘min / max∘max 等)		拒研报 §16 隐性过拟合(2026-08-17 新增)

LLM 终审(过滤16,2026-08-17 接线):候选通过全部 16 项过滤、即将入库前(每轮仅 1-2 个),由 glm-5.3 做最后一道经济学把关——审查 prompt 三类检查:①边界条件(除零/极端窗口/量纲)②经济学含义自洽 ③过度平滑/统计量堆叠。LLM 不可用→放行(不崩);拒→按 #16 记录不入库。

6回测层(alphalab)

backtest/alphalab_adapter.py:因子面板 → parquet(date+股票列,float32,只切回测窗口)→ 子进程 alphalab check(horizon=5,项目专用 yaml)→ 解析结果目录 → FactorMetrics(IC/ICIR/分年多空/NAV/单调性等)。

并发 3 线程
alphalab 子进程等待时释放 GIL;实测 3 为甜点
确定性坏因子拦截
有限值占比 <1% 直接 ValueError,省一次回测
覆盖率防线(2026-08-17)
任一月覆盖 < 前后各 12 个月中位 ×60% → 回测前拒并永久去重;防嵌套时序算子 min_periods=n 的 NaN 乘性放大(2019-04 inf 事故曾把 2 个坏日放大成 40 交易日瘫痪)
异常容错分类
瞬时错误(alphalab 抖动)不标已测→下轮重试;确定性 ValueError → 永久去重,防同表达式反复白评估

结果目录与输入 parquet 解析完即删(防爆盘);keep_output=True 可保留调试。

9Loop 调度(链式 + 高峰暂停)

节奏

Claude /loop 链式触发:完成上一轮立刻诊断并启动下一轮(每轮 ~10-16 分钟);或 OS cron 直跑脚本(方式 A,零调度 token)。

高峰暂停规则(用户 2026-08-15 拍板)

每天(含周末)9:00-12:00、14:00-18:00 暂停;午休(12-14)与夜间(18-次日9)照常。脚本级兜底:run_round_cli.py 启动即查北京时间,高峰直接"跳过本轮"退出;--force 可显式越过(仅用户手动指定时用)。暂停期用 CronCreate durable 一次性唤醒(12:02 / 18:02)续链,会话重启不丢。

每轮监控行(loop.log)

BUDGET: yielding(近5轮均入库1.0)→利用+(变异/交叉) | mutate/crossover/perturb/random/llm = 0.3/0.3/0.15/0.1/0.15
轮次 363: 生成 100 → 新测 47 → 审查过 37 → 回测 37 → 入库 1(累计 19) [10.3min]
REJECT分类: 相关性高×20, 某年负×17, ..., 同构家族×7, 审查:过度平滑×1, 审查:极值嵌套×1, 审查:覆盖率×n, LLM终审×n
LLM: 生成 ok12/解析失败1/API错0/兜底0 | 终审 ok1/错0          ← LLM 健康度(2026-08-17 新增)
STATUS: iter=363 tested=14590 stored=19 new=1 elapsed=10.3min workers=3
SIGNALS: {'iteration': 363, 'stored_total': 19, ..., 'stuck_rounds': 0, 'top_abs_ic': 0.0737}
相关性体检: 两两 136 对,≥0.7 共 0 对                        ← lib_status(hook 每轮自动,2026-08-17 新增)

诊断边界(编排器自动执行)

stuck_rounds ≥8 且无果
停下报告用户,不空转烧 token
回测异常增多
基线 0-4/轮为并发抖动(失败候选自动重试);持续 ≥10 → 查 rqdatac/降并发
存量相关漂移
#9 是入库门槛非持有门槛——lib_status 每轮体检,≥0.7 对自动亮出(0007 与第一名 0.78 即被坏数据掩盖的存量违规,复检后移除)
高风险动作
删 checkpoint / 改 .env / 动 alphalab 配置 → 先问用户

LLM 接入(glm-5.3,2026-08-17 切换)

智谱 Coding Plan key 走 /api/anthropic(Anthropic Messages 格式,与 Claude Code 同端点同 key,不扣按量余额;两套端点计费独立——v4 端点会报 1113 余额不足)。AnthropicMessagesProvider 超时 120s、max_tokens 4096(GLM_TIMEOUT / GLM_MAX_TOKENS 可调)。生成/审查各有 random_tree 与放行兜底,LLM 全挂也不崩轮。
